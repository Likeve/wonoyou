# INOU 开发进度

2026年11月7日，0.1 开发版，增加 Vercel + Redis 部署适配。

## 当前可用

微信式响应式界面、身份创建和口令解锁、邀请码单方加好友、WebRTC 文字和图片、接收端落库回执、离线待发及重试去重、加密本地数据库、离线查看历史、加密档案导入导出、本地备注、删除与拉黑、PWA 缓存与安装元数据。

服务器仅保存公钥与关系元数据，不提供聊天存储和附件上传接口。前端和服务通过同源 `/api`、`/signal` 通信。

## 当前验证

- 服务层 6 项集成测试通过，包括身份认证、邀请码并发核销和权限拒绝。
- 生产构建通过，离线应用壳和安装图标已生成。
- npm audit 全部依赖无已报告漏洞。
- 双独立 Chromium 身份完成真实 WebRTC 通信；不是模拟消息或 BroadcastChannel。
- 已验证文字双向送达、离线补发、去重、图片、错误口令拒绝、本地加密、历史重载、加密导出与重复导入。
- 手机宽度 390 px 与桌面宽度 1280 px 已做视觉检查。
- 真实 Upstash Redis 上的双实例测试通过：跨实例认证、原子核销、信令、实例重启、封禁与无内容落库。
- Redis 后端上的 15 项浏览器回归检查通过，无页面运行错误。
- Vercel Preview 部署状态为 Ready，构建输出包含 `api/backend` 函数；链接见 `Vercel部署说明.md`。

## 进入手机内测前

1. 完成最终 HTTPS 域名和访问方式确认；固定域名需填写同源来源限制。Vercel 资源与部署操作见 `Vercel部署说明.md`。
2. 配置自有 STUN/TURN，检查跨网连通、配额和载荷日志策略。

4. 加密协议独立审查；当前使用 WebRTC DTLS 和身份签名信令，尚无应用层 Double Ratchet。
5. 将整库加密快照迁移到分记录加密存储，验证大量历史及附件性能。

PWA 关闭后不会常驻接收。推送通知、身份迁移、多设备和语音仍未实现。公网双设备收发与 iOS 真机尚未验收。
